# 介面與操作流程改善紀錄

日期：2026-09-07。檢查基準：`a8caacb`，原始工作目錄乾淨，428 項離線測試通過。

## 原始狀態

專案已有雙向擷取、翻譯、TTS、浮動字幕、場景、診斷、模型下載、紀錄與匯出能力，並有獨立背景控制器。主要問題是功能集中在單一長表單，基本模式隱藏部分常用操作；進階模式則將大量設定及工具同時展開。

這次追蹤 GUI → controller → engine 的啟動、停止、背景結果、音訊裝置與字幕操作，沿用既有架構與相依套件。設計依據見 [DESIGN.md](../DESIGN.md)。

## 已實作

| 問題 | 改善 |
| --- | --- |
| 主操作與狀態隨內容捲走 | 固定頂部操作列、底部狀態列與進階開關 |
| 所有設定混在長清單 | 四組設定分頁，保留基本／進階模式與鍵盤切頁 |
| 缺少明確文字欄位儲存入口 | 加入儲存按鈕與 Ctrl+S，沿用既有驗證及同意流程 |
| 工具難以尋找 | 加入工具搜尋；基本模式開放重新整理、交換語言、複製及匯出 |
| 主視窗看不到字幕內容 | 加入最新字幕預覽與空白提示 |
| 基本狀態資訊過長、勾選項分散 | 簡化基本摘要並將選項排成兩欄 |
| 中文字型回退造成重疊 | 使用 Microsoft JhengHei UI；統一深色 ttk 樣式與文字層級 |
| 裝置選單含錯誤方向端點 | 麥克風只列輸入；喇叭及 TTS 只列輸出；保留離線已選端點提示 |
| 裝置載入前儲存會清掉既有選擇 | 標籤尚未解析時保留已儲存的裝置識別 |
| 重複按住說話事件會覆寫原靜音狀態 | 按住與釋放具冪等性，支援空白鍵與失焦還原 |
| 啟動中按停止後仍可能開始 | 停止會取消具固定名稱的啟動檢查 |
| worker 已完成但結果尚未套用時無法取消 | 背景工作保留取消權至 UI 交付；取消後不套用結果 |
| 啟動失敗遺留 writer／擷取資源 | 失敗路徑清理引擎且保留原始錯誤狀態 |
| 單一 UI callback 例外使事件泵永久停止 | 回報例外後繼續處理及排程 UI 更新 |
| 匯出忽略設定驗證及損毀紀錄錯誤 | 驗證失敗中止；讀寫／解析失敗顯示錯誤 |
| 滾輪誤捲主內容、啟動及暫停狀態不清楚 | 限定捲動範圍；執行期間停用開始，暫停按鈕顯示下一個動作 |

## 驗證與範圍

- GUI 回歸測試涵蓋事件例外、重複按住說話、裝置方向、啟動取消、設定保留、匯出失敗。
- Controller 回歸測試涵蓋晚到結果取消、啟動失敗清理、保留錯誤訊息及引擎參照競態。
- 真實 Tk 視窗使用暫存設定與模擬服務，檢查繁中基本模式 1000×760、英文進階模式 720×520 的分頁、欄位邊界、搜尋及固定操作列；擷取指定視窗檢查排版。
- 完整驗證指令：`scripts/test.ps1`（unittest discovery 與 compileall）。
- 結果：438 項測試全部通過，compileall 通過；最後狀態回饋修正後另重跑 71 項 GUI 測試通過。視窗檢查亦驗證浮動字幕清除後仍可複製主視窗最新字幕。

修改檔案：`realtime_audio_translator/gui.py`、`localization.py`、`app_controller.py`、`engine.py`；`tests/test_gui_logic.py`、`test_app_services.py`；`README.md`、`DESIGN.md` 與本文件。

本輪未使用真實麥克風／VB-CABLE、雲端憑證或下載大型模型，也未重新封裝安裝程式。跨螢幕 DPI、實際音訊延遲及完整硬體路由仍需實機驗證，不能由離線測試推定。

已知原有警告：目前 Python 回報 `PurePath.is_reserved` 將於 3.15 移除；專案支援範圍為 3.10–3.13，本輪未擴大版本相容範圍。這是本輪可確認問題的修正紀錄，不代表所有硬體、網路及執行條件都已窮盡。
