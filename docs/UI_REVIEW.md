## 2026-10-24 部署、效能與操作細節

基準 `f958ab3`，497 項測試通過。

| 已確認問題 | 修正 |
| --- | --- |
| 每次按「開始」都要驗證 5,687 個 runtime 檔案；路徑檢查對每個檔案重複 `resolve`／`stat`，共 48,296 次 `resolve`、41,911 次 `stat`，之後辨識器又再雜湊一次並重跑 CUDA probe | 樹狀檢查每個檔案只 `lstat` 一次，並回傳檔案清單給 manifest 驗證，不再走第二次樹；辨識器載入 DLL 前仍完整雜湊，但不再重跑 CUDA probe。暖快取實測：中繼資料 19.4–20.8 → 1.4–1.6 秒，完整雜湊 24.1–26.5 → 6.4–6.8 秒 |
| 啟動檢查期間只顯示「正在檢查啟動需求」 | 改為說明約需 10–30 秒且可按停止取消 |
| README、快速入門、發布說明、診斷與 runtime 提示、安裝程式錯誤都指向不存在的「手動匯入 runtime」 | 統一為實際按鈕「匯入已解壓 runtime」 |
| 語言、翻譯服務、TTS、效能模式、翻譯風格、紀錄內容選單只顯示代碼；來源與目標語言可輸入任意文字 | 顯示「名稱 (代碼)」並改為唯讀下拉；設定檔仍存代碼，舊值與純代碼仍可讀 |
| clam 勾選框選取時畫 ✗，容易被讀成關閉 | 自繪 ✓ 圖示，含懸停與停用狀態 |
| runtime 未就緒提示為灰色次要文字 | 需要處理時改用警示色 |
| 拖曳主視窗時，每個 Configure 事件都重新計算字幕列位置並呼叫 `geometry` | 每個 idle 週期只檢查一次，位置未變時不呼叫 `geometry` |
| `build.ps1` 未檢查 pip 結束碼；`package.ps1` 失敗後殘留 `_stage_*`，使 `-AppendOutput` 重跑失敗 | 安裝失敗即中止；打包前後都清除暫存資料夾 |

驗證：`scripts/test.ps1` 500 項通過，compileall 與 `git diff --check` 通過；兩個 PowerShell 腳本通過語法剖析。以實際 Tk 視窗在 175% 縮放截圖確認繁中基本、進階與英文 720×520 的語言名稱、✓ 勾選框與警示色。

限制：未實際執行 PyInstaller 建置與安裝程式封裝；`requests` 頂層匯入約佔 0.5 秒啟動時間，因 `providers` 型別與例外處理依賴而未延遲匯入。開始流程仍會雜湊兩次（啟動檢查與載入 DLL 前各一次），刻意保留作為載入前的完整性防護。

## 2026-10-23 介面重構

基準 `50415cc`，494 項測試通過。以 175% 縮放實際截圖檢查繁中基本／進階、英文 720×520，並追蹤按鈕狀態與背景工作流程。

| 已確認問題 | 重構 |
| --- | --- |
| 程式未宣告 DPI 感知，125%／175% 縮放時整個視窗被點陣放大而模糊 | 啟動時宣告系統 DPI 感知；視窗、最小尺寸、間距、換行寬度、字幕列與對話框依 DPI 換算 |
| 進階模式 43 個工具按鈕平鋪成同一格，另有 3 個 runtime 按鈕獨立一列，難以尋找 | 分成 7 組 LabelFrame；搜尋只顯示符合的分組；runtime 三個按鈕併入「模型與 runtime」 |
| 「切換字幕／語音／喇叭／麥克風」與既有勾選框完全重複 | 移除 4 個重複按鈕與對應函式，保留勾選框 |
| 下載模型期間除停止外所有按鈕都停用，可能長達數分鐘 | 模型與離線翻譯模型下載不鎖定介面；其他背景工作仍維持互斥 |
| 靜音按鈕未執行時仍可按但無作用，也看不出目前狀態 | 未執行時停用；按鈕文字顯示下一個動作 |
| 「停止」在閒置時可按 | 只在引擎存在或啟動檢查中啟用 |
| 基本模式在主畫面顯示整段 runtime 安裝路徑與檔案清單，且提示的匯入按鈕只在進階模式 | 基本模式改為「請按一鍵診斷查看安裝步驟」；完整內容留在進階模式與診斷 |
| 常用開關排在狀態摘要之後；翻譯風格是可輸入任意值的欄位 | 開關移到設定分頁正下方；翻譯風格改為下拉選單 |
| 診斷／設定指南對話框為白底等寬字型 | 套用深色主題與介面字型 |

驗證：新增按鈕狀態（閒置、下載中、啟動檢查、執行中靜音標籤）、工具分組完整性與控制器 `busy_except` 測試；`scripts/test.ps1` 全部通過。以真實 Tk 視窗確認搜尋 "TTS"／"runtime"／無結果時的分組顯示、字幕列 1575×168 置於工作區底部中央、對話框尺寸。

後續同日追加：

- 啟動時 runtime 或模型缺失，原本只彈出錯誤框；改為說明對話框並提供「匯入已解壓 runtime」、「下載上游 runtime」、「下載模型」與「一鍵診斷」按鈕。
- `_build` 拆為樣式、變數、外框、設定、開關、摘要與工具 7 個建構方法，行為不變。
- 視覺：色彩集中為 `THEME`；頂部／底部列加深並以邊界線分隔；勾選框、分頁、捲軸、下拉箭頭與焦點邊框改為深色主題配色；修正選取分頁高度跳動；工具分組標題加粗；浮動字幕兩行改為不同顏色。

限制：系統 DPI 感知在不同縮放的副螢幕仍由 Windows 縮放；舊版儲存的字幕座標是虛擬化座標，升級後首次位置可能偏移，但仍會限制在可見範圍。執行中的靜音按鈕狀態僅以假引擎測試，未接實際音訊裝置。暫停期間已開始處理的片段仍會完成，維持既有行為。

## 2026-09-07

日期：2026-09-07。檢查基準：`a8caacb`，原始工作目錄乾淨，428 項離線測試通過。

## 原始狀態

專案已有雙向擷取、翻譯、TTS、浮動字幕、場景、診斷、模型下載、紀錄與匯出能力，並有獨立背景控制器。主要問題是功能集中在單一長表單，基本模式隱藏部分常用操作；進階模式則將大量設定及工具同時展開。

這次追蹤 GUI → controller → engine 的啟動、停止、背景結果、音訊裝置與字幕操作，沿用既有架構與相依套件。設計依據見 [DESIGN.md](../DESIGN.md)。
